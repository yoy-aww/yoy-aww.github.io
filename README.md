# yoy-aww.github.io

个人网站，部署于 GitHub Pages。

## 页面

| 文件 | 说明 | 预览 |
|------|------|------|
| `index.html` | 个人作品展示集 — 6 个项目卡片 | [访问](https://yoy-aww.github.io/) |
| `dashboard.html` | VPS 服务总览 — 端口、服务、安全状态一览 | [访问](https://yoy-aww.github.io/dashboard.html) |

## 功能

- 明暗主题切换（localStorage 持久化）
- 响应式布局（移动端适配）
- 纯静态，零依赖，无需构建

## 项目结构

```
├── index.html        # 首页 — 作品展示
├── dashboard.html    # 仪表盘 — VPS 服务总览
├── favicon.png       # 站点图标
└── README.md
```

## 部署

推送到 `master` 分支即可，GitHub Pages 自动构建。
