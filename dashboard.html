🚨 高风险 — LibreDB Studio (:8897)

Docker 直接映射到公网、无鉴权返回 200。任何人只要能连上就能操作你的数据库连接。

建议：至少绑到 Tailscale 内网地址，或加 Nginx 反向代理 + Basic Auth。

公网裸奔，是被扫描爆破的重灾区。宝塔有登录保护还好，phpMyAdmin 建议改路径或限 IP。
